# Alexandria Johnson

## Technical Program Manager | L&D leader scaling technical and AI skilling | Instructional design | Event management

**Learn, build, scale.**

I lead learning and development for technical teams, which means taking something ambiguous and cross-org and turning it into a skilling program that actually runs, then keeps running.

L&D is the part I'm best at: instructional design, event management, adult learning, building things people actually finish. What sets me apart is that I can go technical. I supported AI skilling at Microsoft, so I'm as comfortable with the tooling and program mechanics as I am with the learning design.

In FY26, that meant 121 events and 36,900 attendees, plus reusable kits and resource hubs so teams could run programs independently. I care about reach, but mostly about whether the learning is any good once someone shows up.
