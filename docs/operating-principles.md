# Operating principles

This repo is my public story: the portfolio site and walking deck. Every change is measured against these principles. Confirmed 2026-11-19. It follows the cross-repo contract kept in my private Role-Ops repo (`docs/cross-repo-contract.md`).

1. **Purpose:** a recruiter sees my lane in 10 seconds. The repo supports my return to a PM role and uses one identity line: a PM known for turning ambiguous cross-org AI skilling into repeatable systems.
2. **Public only:** no contacts, unpublished metrics, or employer-confidential details.
3. **Evidence comes from Role-Ops:** every number traces to the verified evidence inventory there. This repo stores no resume or LinkedIn copy.
4. **I publish:** agents work on branches. Only I merge to `main`, because merging publishes the site.
5. **Code before models:** Marp builds, `get_errors`, and `git diff --check` do the checking.
6. **Quarterly review,** alongside the vault charter (next: 2027-02-18). Drop anything unused.
